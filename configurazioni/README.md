# Le configurazioni salvate

A ogni missione superata, nel simulatore scrivi `/export` (oppure il bottone «Export della configurazione»), copia il testo e salvalo qui in un file nuovo, con un commit:

1. Clicca «Add file», poi «Create new file».
2. Nome del file: `missione-1.rsc` (poi `missione-2.rsc`, e così via).
3. Incolla il testo dell'export e clicca «Commit changes», con un messaggio come «Missione 1: indirizzo alla rete interna».

Così si vede, commit dopo commit, come cresce la configurazione del tuo router.
